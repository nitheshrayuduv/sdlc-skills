# sdlc-skills
This repo contains generic SDLC skills and its mandate process during different phases

## Skill-driven Spec Kit workflow

`speckit-extensions/sdlc-skills` (extension) and `speckit-extensions/org-sdlc` (preset) run vendored skills at clarify, plan, tasks and implement. Install with `installer/install.py`; design is in `docs/specs/spec-kit-extension-spec.md`.
